# Capabilities

The same pieces, carrying three capabilities that aren't conventional apps: a leave request, a change to a supplier's bank details, and an access request. Each draft puts what needs the person first, folds the rest with its sources, and waits to be sent. A showcase page.

A capability gives the kit four things (docs/conversation.md): what the outcome needs and where each value can come from; the rules it checks, which become questions; what sending it does, and who decides next; and its stages, and until when it can be taken back.
