# Status

How the outcome stands, brought to the person: where it is, who it waits on, what comes next, and how long it can still be taken back.

- Its stages, in order: done with a tick, the one now with a clock and who it waits on, the rest to come.
- Until when the person can take it back (recall, withdraw), and the button to.
- The agent says it will message the person when it moves, so nobody has to check.

It belongs to the conversation kit (docs/conversation.md), for any capability, not one kind of app. Here it tracks an access request, which ends by itself.
