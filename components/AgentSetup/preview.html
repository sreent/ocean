Connect an agent

  1. Create a token for it

    Copy it now. This is the only time a4a shows the token claude-code: it keeps only a fingerprint of it.

    a4a_9Kd2mQ7xT4vB8nR1cL6wZ3pH5jY0sF2g
    Copied the token.

  2. Add a4a to the agent

    Run this in a terminal, in the folder you work in.

    claude mcp add --transport http a4a https://a4a.example.com/mcp --header "Authorization: Bearer a4a_9Kd2mQ7xT4vB8nR1cL6wZ3pH5jY0sF2g"
    It has the token claude-code in it.
