# LogicKinds

Every kind of step in a3t's flows, as LogicNode draws it, with what Mendix calls it, for builders who know Mendix. The set comes from a3t's app definition (`sreent/joget`, `packages/app-model`). A showcase card, proposed.

- Where a flow starts, waits and ends: rings. A flow that waits is a flow like any other. Its waits and its person's tasks are steps, not a second kind of drawing.
- Records: a find reads; a create, a change, a new line and a delete change. A delete stays with a person.
- Logic: a decision, and where ways meet; frames for a loop, for an error handler, and for steps at once; a value set, a count or a total, and a check that stops or warns; a flow or an action run from a flow, its icon in the colour of what it does.
- People, and what lies outside: a person's task, with a way on for each outcome; the first of several waits; a deadline that hangs below a task; and a service called through a named connection, which crosses the edge.

A new kind comes from a3t's definitions, never from a canvas alone, and Ocean draws it here first.
